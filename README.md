# 🛍️ Projeto Integrador - ReCloset

## 📖 Sobre o projeto

O **ReCloset** é um projeto desenvolvido para a disciplina de **Projeto Integrador** do curso de **Análise e Desenvolvimento de Sistemas (ADS)**.

A proposta do sistema é criar uma plataforma de brechó online, permitindo que usuários comprem, vendam e favoritem peças de roupas e acessórios de forma prática e sustentável.

O projeto está sendo desenvolvido utilizando **HTML, CSS, Python, APIs e integração com banco de dados**.

---

## 🎯 Objetivo

Desenvolver uma aplicação web para incentivar a reutilização de roupas e acessórios, promovendo a moda sustentável e facilitando a conexão entre compradores e vendedores.

---
